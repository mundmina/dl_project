# Background Bias in Image Classification

CSCI 494: Deep Learning · Amina Abdikalyk, Islam Sanatbek, Tomiris Rakymbay, Assylkhan Tleubayev

Does a breed classifier look at the animal, or does it use the background as a shortcut?
And does random background replacement during training reduce that dependence?

- Data: Oxford-IIIT Pet (37 breeds, trimap masks); backgrounds from Places365 (val, 256px).
- Models: HOG + linear SVM · ResNet-18 A (original images) · ResNet-18 B (50% random background swap).
- Test conditions: original · background-swapped · foreground-only (+ background-only as a diagnostic).

Full plan, decisions and schedule: [`PLAN.md`](PLAN.md).

## Running

Everything runs in **Google Colab** (Runtime → T4 GPU). Each notebook clones this repo, mounts Drive and
caches dataset archives in `MyDrive/bgbias/data/`.

| Notebook | What it does |
|---|---|
| [`00_setup`](https://colab.research.google.com/github/mundmina/dl_project/blob/main/notebooks/00_setup.ipynb) | Environment check, dataset download + Drive cache |
| [`01_data`](https://colab.research.google.com/github/mundmina/dl_project/blob/main/notebooks/01_data.ipynb) | Splits, mask audit, background pools, fixed val/test backgrounds, example gallery, DataLoader smoke test |
| [`02_hog_svm`](https://colab.research.google.com/github/mundmina/dl_project/blob/main/notebooks/02_hog_svm.ipynb) | HOG + linear SVM baseline, C chosen on validation |
| [`03_train_resnet`](https://colab.research.google.com/github/mundmina/dl_project/blob/main/notebooks/03_train_resnet.ipynb) | Train ResNet-18 A or B for given seeds (resumable, checkpoints on Drive) |
| [`04_evaluate`](https://colab.research.google.com/github/mundmina/dl_project/blob/main/notebooks/04_evaluate.ipynb) | All models × all conditions → predictions, metrics, main table (val by default, test once at the end) |

## Layout

```
src/bgbias/      code (notebooks only call it)
  data_setup.py  download + Drive cache
  splits.py      stratified train/val split, official test, image/mask audit
  backgrounds.py Places365 pools (disjoint scene categories) and fixed eval manifests
  compose.py     trimap -> soft alpha, background swap, neutral / background-only variants
  datasets.py    PyTorch Dataset for all test conditions + random swap for training
  project.py     loads splits/manifests/pools, builds datasets
  models.py      ResNet-18 with a 37-class head
  train.py       training loop: AMP, cosine LR, best/last checkpoints, resume
  hog_svm.py     HOG features + linear SVM
  evaluate.py    predictions per condition, accuracy / macro F1 / gaps / flip rate, seed aggregation
configs/         resnet_A.yaml / resnet_B.yaml (identical except p_swap)
notebooks/       Colab notebooks
splits/          train/val/test CSV (generated by 01_data, committed)
manifests/       background pools and fixed val/test backgrounds (committed)
results/         metrics and audits (small files, committed)
report/          report and figures
```

Large files (datasets, checkpoints) live on Google Drive, not in git.
